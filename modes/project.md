# Mode: Portfolio Project Evaluation

Evaluate whether a portfolio project idea is worth building given the candidate's career goals.

## Evaluation Criteria

1. **Signal value**: Does this demonstrate skills that target roles require?
2. **Differentiation**: Does this set the candidate apart from other applicants?
3. **Effort vs. impact**: Time to build vs. career value generated
4. **Showcaseability**: Can this be demoed in interviews or linked in applications?
5. **Learning value**: Does building this fill genuine skill gaps?

## Output

- Score (1-5) for career impact
- Recommendation: Build it / Skip / Modify scope
- If build it: suggested scope, timeline, and tech stack
- How to feature it on CV and in applications
