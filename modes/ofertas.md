# Mode: Compare Offers

Compare and rank multiple evaluated offers side by side.

## Pre-flight

1. Read `data/applications.md` for tracked applications
2. Read the individual reports for each offer being compared

## Comparison Dimensions

| Dimension | Weight |
|-----------|--------|
| CV Match | 25% |
| North Star Alignment | 20% |
| Compensation | 15% |
| Culture & Work Style | 15% |
| Red Flags | 15% |
| Global Score | 10% |

## Output

Side-by-side comparison table with:
- Score breakdown per dimension
- Pros and cons for each
- Final ranking with recommendation
- Suggested application priority order
