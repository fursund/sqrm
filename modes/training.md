# Mode: Training Evaluation

Evaluate whether a course, certification, or training program is worth pursuing given the candidate's career goals.

## Evaluation Criteria

1. **Relevance to target roles**: Does this skill appear in JDs for target archetypes?
2. **Market signal**: Is this certification recognized/valued by hiring managers?
3. **Time vs. impact**: How long to complete vs. how much it moves the needle?
4. **Existing gaps**: Does this fill a genuine gap in the candidate's profile?
5. **Alternative signals**: Could the same skill be demonstrated via a project instead?

## Output

- Score (1-5) for career impact
- Recommendation: Worth it / Skip / Consider alternative
- If worth it: suggested timeline and how to feature it on CV
